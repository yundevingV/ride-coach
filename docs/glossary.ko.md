# 용어집 (ride-coach)

**English:** [glossary.md](glossary.md)

AI가 사용자에게 결과를 설명할 때 **아래 한글만** 사용.

## 파워

| 한글 (사용자) | 영문 (코드/JSON) | 설명 |
|---------------|------------------|------|
| **기록 파워** | rawAvgW, watts | Strava 표시 W. 바람·노면 영향 포함 |
| **바람 보정** | windDeltaW | 풍속·풍향·진행방향으로 가감하는 W. 역풍 + |
| **노면 보정** | surfaceDeltaW | 젖은 노면 추가 저항 W |
| **보정 파워** | zeroWindW | 기록 + 바람 보정 + 노면 보정 (날씨 다른 날 비교용) |
| **업힐 보정 파워** | climbZeroWindW | 경사 3%+ 구간만의 보정 파워 평균 |
| 정규화 파워 | NP | Strava NP. 별도 날씨 보정 없음 |

**보정 파워 = 기록 파워 + 바람 보정 + 노면 보정** (체인손실 반영)

## 날씨

| 한글 | 필드 | 설명 |
|------|------|------|
| 풍속 | windKmh | km/h |
| 풍향 | windFromDeg | 바람 **오는** 방향 (북=0°) |
| 역풍 구간 | headwindPct | 역풍 샘플 비율(%) |

## 노면

| 한글 | 조건 |
|------|------|
| 건조 | 당일 강수합 ≤5mm |
| 젖음 | 당일 강수합 >5mm 또는 해당 시 강수 >1mm |

## 출력 예시

> 기록 파워 106W, 바람 보정 +6W → **보정 파워 112W** (역풍 48%)

## 심박 (훈련 강도)

**기본: Intervals.icu LTHR 7존** (% of LTHR). **LTHR(bpm)** 은 대화에서 사용자가 말한 Intervals 설정값만 쓴다 — repo·스킬에 개인 기본값 **저장하지 않음** (미상이면 확인).

| 존 | 이름 | LTHR % | bpm (LTHR = *T*) |
|----|------|--------|------------------|
| Z1 | 회복 | &lt; 81% | &lt; 0.81×*T* |
| Z2 | 유산소 | 81–89% | 0.81×*T* ~ 0.89×*T* |
| Z3 | 템포 | 90–93% | 0.90×*T* ~ 0.93×*T* |
| Z4 | 서브역치 | 94–99% | 0.94×*T* ~ 0.99×*T* |
| Z5 | 역치 | 100–102% | *T* ~ 1.02×*T* |
| Z6 | VO₂ | 103–106% | 1.03×*T* ~ 1.06×*T* |
| Z7 | 무산소 | &gt; 106% | &gt; 1.06×*T* |

**추정 파워(속도계)** 라이더: **오늘 강도 맞췄나(Z2 등)** → **심박 7존 우선**. 라이덕·FTP **파워 7존**은 부하·앱 분포 참고용 — **심박 존 이름으로 쓰지 않음**.

| 쓰지 않음 (사용자가 명시할 때만) | 이유 |
|----------------------------------|------|
| Strava `get_athlete_zones` 기본 5존 | Intervals와 불일치 |
| 가민 % 최대심박 5존 | LTHR 기준과 다름 |
| 라이덕 FTP % **파워** 7존 | 심박이 아님 |

데이터: `heartrate` streams, 동일 세션 Workout(Mi Band `.fit`), `--fit` / `--hr-streams`. **날짜·PR 비교**는 여전히 **시간 → 보정 파워** (`segment-analysis.ko.md`).

## 피해야 할 표현 (사용자 응답)

- ❌ raw W, zero-wind, **무풍 등가 파워**, zero-wind W
- ✅ 기록 파워, 바람 보정, **보정 파워**
- ❌ 심박을 **맥스 % 5존**·**파워 존**으로만 설명 (Intervals LTHR 7존 미적용)
